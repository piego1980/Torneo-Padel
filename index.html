Regole torneo

Le regole operative utilizzate nel torneo.

⏱30 min per match — 5' riscaldamento + 25' di gioco. Se il turno precedente sfora, si riduce il riscaldamento successivo.
🎾Set unico — vince chi totalizza più game. Allo scadere del tempo si completa il game in corso.
🏆Parità di vittorie: 1° Scontri diretti · 2° Differenza game (vinti − persi) · 3° Game totali vinti.
